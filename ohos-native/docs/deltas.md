# 鸿蒙原生版差异与验证边界

更新：2026-08-24。本表只记录 HarmonyOS 原生版相对 Android v1.0.8 的平台差异和当前未完成的设备级验证。业务规则、数据安全规则和用户可见结果不以“平台不同”为由静默降级。

## 本轮已确认

- “克制工程感”视觉规范、悬浮 Dock、统一表单/设置层级和动态字体批量操作栏已落到 ArkTS 源码并通过编译与策略测试。
- 项目和记录列表已使用惰性数据源；记录固定 50 条分页，具有单飞、去重、局部重试和过期请求丢弃。
- 全屏查看器按数据库窗口读取，最多保留当前照片前后各两张；图片解码上限、稳定占位和回调代次均有自动化覆盖。
- 拍摄/编辑字段校验、模板与建议、单步撤销、设置操作防重、恢复预检/事务/日记/暂存清理均有自动化回归。
- ArkTS 全量测试、鸿蒙数据库契约测试、测试报告防假绿、debug unsigned HAP、共享 Rust 与 Flutter 门禁已通过。日期、命令和证据见[验证记录](verification-2026-08-20.md)。
- 完成新一轮平台能力对齐审计（权限、生命周期、通知、位置来源与触感覆盖面），新发现差异已补入下表；其中通知点击直达、EXIF 位置源、退后台短时窗口与设置跳转兜底已在 ArkTS 源码和策略测试中落地，设备级验证待补。
- 外观页独立「应用主题色」与「水印强调色」两排 9 色选择器；seed / accent 分字段保存；历史 0xFF176B55 / 0xFF2E7D61 选择器高亮新绿但不改写库值。
- Index.build() 读取 appearanceRevision / motionRevision，保存主题色后栈内页跟根壳重绘。
- 详情媒体 overlay 与 BatchActionBar 去掉 backdropBlur；Dock / 选中态仍走 MotionPolicy.blur()。
- 记录页与项目页年月日筛选共用 DateFilterRow，高度与 TOUCH_TARGET / filterControlHeight() 对齐。

本轮 `hdc list targets` 为 `127.0.0.1:5555`（模拟器，非真机）。已按五项冒烟走查，不把模拟器写成真机转正。项 1–2 dump 两排 9 点：未保存点蓝仍 `chrome-1-3`，保存后 `chrome-2-3` 且 AppBar「保存」PRIMARY 变蓝。项 3：外观橙保存后主题仍蓝（`chrome-3-3` / `chrome-4-3`）；新建项目表单无色点，`createProject` 从 settings 拷贝 `defaultWatermarkAccentColorArgb`，创建后项目水印设置可见 `#FFEF6C00`。项 4：项目详情内联年月日三框同高 155、底 `#FFEEF4F0`；记录页 `FilterToolbar` 点击 / longClick / `dumpLayout -i` / `-m false` 后 `bindSheet` 半模态未出现在 uitest dump，年月日三框未拍到，共用 `DateFilterRow` 仅源码确认。项 5：详情 overlay「水印成片」`#FF1565C0`、「原图」`#F4F6FBF8`，选择模式 BatchActionBar 四钮 +「已选 0 张」，dump 无非零 `blur`；Dock `backdropBlur` 源码仍在 Index L361/L378，uitest dump 全为 `0.00px`，不能当视觉证明。记录侧 sheet 与 Dock blur 的 UI 证据不足，故不写「模拟器五项冒烟已过」。真机验证待补。源码约束与单元测试通过不能替代真机结果。

## 平台差异表

| 能力 | 当前实现/结论 | 对用户的处理 | 转正条件 |
| --- | --- | --- | --- |
| 系统相机 | 产品使用 CameraPicker，不声明相机权限；debug 变体保留内置 JPEG 状态机探针 | 探针代码仅 debug 变体生效且不冒充系统相机；probe.jpg 调试资产会打入所有构建（当前预发布 HAP 即 debug 构建） | 真机完成拍摄、取消、旋转、连续拍摄和杀进程恢复 |
| 定位权限拒绝态 | 鸿蒙仅布尔态：永久拒绝后再点“启用定位”仅提示，设置页提供常驻跳转入口（显式应用详情 → bundle+uri → 位置服务页 → details action → 裸设置主页五级候选依次回退，全部失败时页面内联提示手动授权）；Android 为三态并在卡片上自动切“打开设置” | 拒绝定位不影响拍摄；永久拒绝时仍有设置页这条可达授权路径 | 真机验证永久拒绝提示与设置页跳转各候选路径 |
| 位置来源 | 鸿蒙与 Android 同为三级优先：原图 EXIF GPS（图像管线在渲染前读取，结果标记 `locationResolution=exif` 防重复读盘）→ 拍摄瞬间一次性定位（8 秒超时）→ 无 | 拒绝定位时记录如实标记无位置；有 EXIF GPS 的原图可与 Android 对齐地理信息产出率，不虚报坐标 | 真机验证含 EXIF GPS 原图的产出率、一次性定位回退与水印坐标正确性 |
| 后台处理 | 应用存活时串行处理；系统结束后在下次启动对账收敛 | 不显示“应用被结束后仍持续处理”的错误承诺 | 真机验证前后台切换、锁屏、内存回收和重启恢复 |
| 退后台处理窗口 | Android WorkManager 退后台照常执行；鸿蒙退后台时若串行队列仍在处理则申请 `requestSuspendDelay` 短时窗口（到期最多自动续期一次），队列排空或回前台立即取消；仍超窗则回前台续跑、下次启动对账收敛 | 连拍尾部记录在短时窗口内可继续渲染，超窗部分等回前台继续；不显示“后台仍在处理”的错误承诺 | 真机验证退后台后连拍尾部的渲染完成率与窗口续期/取消行为 |
| 完成通知点击 | Android 点通知直达记录详情（deep-link + 冷启动兜底）；鸿蒙 publish 已挂 wantAgent 携带 captureId，点击直达记录详情；冷启动经 PendingNotificationLaunch 暂存、页面运行时就绪后重放，热启动 onNewWant 即时分发 | 通知可靠送达且点击后无需手动导航到记录 | 真机验证通知直达的冷启动、热启动与应用内三条路径 |
| 相册保存 | 私有水印成片完成后，可由记录详情拉起系统确认面板；授权返回目标 URI 后再完整写入 JPEG | 需要交互的系统面板不阻塞连拍；取消或写入失败不改变私有记录 | 真机验证确认、取消、重复保存、目标相册与图片完整性 |
| 相册删除 | 应用记录和私有文件删除后，系统相册副本始终保留 | 不申请受限媒体写权限，不建立无法执行的相册删除队列 | 真机确认单条/批量/项目删除均不影响系统相册副本 |
| 备份恢复 | ZIP 预检、冲突改名、RDB 事务、恢复日记和暂存清理已实现并自动测试 | 失败提供可理解提示，不把部分恢复写成成功 | 设备文件选择器 + 真实 RDB 完成单/多项目、重复恢复、中断恢复 |
| 导出交付 | 项目/批量导出与诊断包完成后优先拉起系统分享面板（`@kit.ShareKit`），面板不可用或失败自动回退文档选择器保存；Android 侧为 share_plus 系统分享面板 | 分享/保存均需用户主动操作；面板调起失败不静默丢文件，仍可保存到本地；取消不误报成功 | 真机验证分享面板调起、跨应用发送、取消与回退保存路径 |
| 动态取色 | 使用工程印记固定强调色与深浅色资源 | 不宣称与 Android Monet 动态取色完全等价 | 平台提供稳定等价能力后再评估 |
| 长列表 | 项目惰性节点、记录 50 条分页、状态恢复与旧请求丢弃已实现 | 追加失败保留已有内容并局部重试 | 设备导入 2,000 条记录，验证滚动、筛选、往返和内存水位 |
| 图片查看 | 列表限尺解码，详情上限 2048；查看器最多 5 条、相邻图上限 1024 | 图片失败保留稳定占位和重试，不闪原始异常文字 | 真机验证 12MP/50MP、连续切换、缩放、geometry 共享转场和内存压力 |
| 跨页面 Hero 转场 | 列表卡片缩略图、记录详情媒体区、查看器当前图三处统一 `geometryTransition`（API 11+，`isSelf` 取系统默认）；系统计时，跟随系统减少动画 | 能力不可用或回退时为默认页面转场，功能不受影响 | 真机走查列表→详情→查看器→返回四条路线：共享转场生效、无闪烁，减少动画时直接跳转 |
| 视觉/无障碍 | 统一 token、悬浮 Dock、动态字体批量栏、44vp 热区和双语语义已实现 | 遵循减少动画；大字体通过策略计算布局 | 中文/英文、浅色/深色、大字体、减少动画四组设备走查 |
| 安装包签名 | 本地可产出 debug unsigned HAP，项目未配置 `signingConfigs` | 仅作为可复现开发产物，不作为正式发行包 | 发布证书签名，并完成全新安装、覆盖安装和卸载边界测试 |
| 首启隐私同意门 | 鸿蒙有首启同意门：同意前不初始化运行时，“退出应用”为显式选择；Android 无首启门（关于页静态隐私说明） | 同意前不读写任何用户数据；为上架合规新增，非能力缺失 | 真机验证首启同意、退出与再次启动流程 |
| 触感反馈 | 进入选择模式 mediumImpact、勾选记录 selectionClick（`@kit.SensorServiceKit` vibrator，time 型短振动）；已声明 `VIBRATE` 权限；Android 批量操作 heavyImpact 与表单提交 lightImpact 场景未映射 | 振动失败静默跳过，不阻塞点击 | 真机确认两类振动的强度与时机；评估补齐批量与表单场景 |
| 自动化 CI | 公用 runner 不预装可再分发的 DevEco/HarmonyOS SDK | CI 校验 manifest 与 Rust/Flutter；ArkTS/HAP 由本地 DevEco 门禁给证据 | 提供合规专用 runner 后补 HAP 远程构建 |
| 窗口沉浸 / 系统栏 | 当前为尝试 edge-to-edge（`setWindowLayoutFullScreen` + 透明栏 + inset 避让）。模拟器 `127.0.0.1:5555` 手势导航 dump 仍见 EntryAbility root y=137 / StatusBar 136px，SCB `immersive is false` | 根壳系统栏保持显示；查看器 immersive-sticky 隐藏系统栏，退出只恢复栏可见性与图标色，窗口不关全屏 | 真机手势/三键/折叠/多窗 |

- [tool/ohos-native/probe.md](../../tool/ohos-native/probe.md) 记录的是早期特定模拟器环境的技术探测，不能作为本轮版本的设备验收结论。
- 当前没有新增模拟器或真机截图；不得添加截图占位、失效链接，或把 debug 探针图片写成产品截图。
- 任何新增平台差异必须先进入本表，再进入发布说明；不允许用原始平台异常字符串替代用户可理解的提示。
