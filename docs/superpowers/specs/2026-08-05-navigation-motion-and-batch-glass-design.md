# SiteMark 导航动效与批量操作栏修复设计

## 目标

本次只处理三项体验问题：

1. 严格按“全部记录 → 项目 → 项目详情 → 返回”的路径，消除返回过程中闪现“全部记录”照片列表的问题。
2. 三个底部 Dock 入口点击切换时，页面按入口顺序左右滑动；选中背景改为随页面同步移动的玻璃滑块。
3. 照片多选操作栏恢复为一整块玻璃面板，去掉四个操作项各自的框选背景，只保留图标、文字和轻微点击反馈。

## 根因与导航边界

项目详情当前通过 `parentNavigatorKey: rootNavigatorKey` 放在三个根分支共同的最外层导航器。详情页返回时，外层路由转场可能短暂暴露已经绘制过的“全部记录”分支；现有测试只验证最终分支索引，没有验证返回动画中间帧，因此未能拦住该问题。

项目详情改由“项目”分支自己的导航器承载。进入和返回详情只在项目分支内部发生，“全部记录”分支不参与详情转场。底部 Dock 继续根据当前路径隐藏，因此项目详情仍保持全屏显示。

## Dock 页面切换

- 三个根页面保持各自的搜索、筛选、滚动位置和加载状态。
- 点击更靠右的入口时，当前页向左退出、目标页从右进入；点击更靠左的入口时方向相反。
- 从第一个入口直接切到第三个入口时只执行一次短距离滑动，不经过中间页面。
- 动画期间只绘制当前分支和目标分支；结束后其他分支停止绘制、交互、语义和动画。
- 不增加手指横向拖动切页，避免与照片浏览和列表手势冲突。
- 系统开启“减少动画”时立即切换。

## Dock 玻璃滑块

- Dock 外层继续使用现有玻璃面板。
- 选中态只使用一个可移动滑块，不为三个按钮分别创建选中背景。
- 滑块通过半透明高光、细边框和柔和阴影形成玻璃质感，共用外层模糊结果，不叠加新的实时模糊层。
- 滑块与页面切换使用同一时长和方向感；图标与文字颜色同步渐变，位置始终居中。
- 点击热区、无障碍标签和大字体下的可读性保持不变。

## 照片多选操作栏

- 外层保留单一 `GlassSurface`。
- 已选数量继续显示在左侧。
- 导出所选、保存到相册、清理原图、全部删除均显示图标和文字。
- 四个操作项背景保持透明，不显示独立圆角框或色块。
- 点击时只显示轻微水波或按压反馈。
- 删除操作仅使用错误色图标和文字；禁用操作降低前景透明度。
- 现有操作逻辑、确认、撤销和进度行为不变。

## 验证标准

1. 自动化测试使用真实 Dock 点击顺序复现“全部记录 → 项目 → 项目详情 → 返回”。
2. 在返回动画开始、中间和结束帧，均不得绘制“全部记录”的照片列表。
3. 根页面向左、向右及跨两个入口切换时，页面位移方向正确，非参与分支不绘制。
4. 玻璃滑块只有一个，并随选中入口平滑移动；减少动画模式下立即定位。
5. 多选操作栏保持一块玻璃背景，四个操作项没有独立填充背景，同时文字可见且点击行为不变。
6. 完整 Flutter 测试、静态检查以及 Android 构建均通过后才能提交合并。

## 不在本次范围

- 不增加手势拖动切换根页面。
- 不修改照片处理、数据库、备份恢复或水印逻辑。
- 不在本次修复中自动发布新版本；合并与版本发布由后续确认决定。
