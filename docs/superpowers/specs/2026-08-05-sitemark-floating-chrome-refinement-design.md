# SiteMark 悬浮导航与记录列表精修设计

> 日期：2026-08-05
> 状态：已确认，待实施

## 1. 目标

本轮只解决三项真机体验问题：

1. 从项目详情返回项目首页时，记录照片不得横向闪过或短暂重排；
2. 一级 Dock 必须真正悬浮，记录日期不再使用全宽分隔条；
3. 批量选择时不得叠加第二块底栏并明显压缩照片区域。

项目、照片、筛选、批量操作及后台处理的数据契约保持不变，不新增依赖。

## 2. 统一悬浮层

一级页面不再通过 `Scaffold.bottomNavigationBar` 放置 Dock。根页面改为覆盖式布局：页面内容铺满可用高度，玻璃 Dock 通过底部安全区之上的定位层悬浮显示。

- Dock 四周保留外边距、圆角、阴影或边框，不绘制贯穿屏幕的底色和分割线；
- 列表内容可以滚动到 Dock 后方，但末尾必须有足够的滚动留白，最后一项能够完整露出；
- 项目首页的新建按钮与 Dock 保持固定间距，不互相遮挡；
- 二级页面仍隐藏一级 Dock；
- 开启“减少动画”后，Dock 状态直接切换，不执行位移或淡入。

## 3. 记录日期

全部记录页顶部保留一行紧凑工具区：左侧为“筛选”，右侧为当前日期标签。列表中的全宽吸顶日期条全部移除。

- 初次进入时显示最新一组可见记录的日期；
- 滚动跨越日期分组时，右侧日期自动更新为当前可见分组；
- 精确筛选到某一天时，日期固定显示筛选日期；
- 没有记录时不显示日期；
- 日期变化不触发列表刷新、筛选查询或滚动跳转；
- 每张记录本身仍显示短日期和当日编号，无障碍语义不会依赖顶部日期标签。

`CapturePagedList` 负责报告当前可见日期，页面只负责显示，不把滚动观察逻辑放进筛选组件。

## 4. 批量选择 Dock

批量选择不再使用 `Scaffold.bottomNavigationBar`。进入选择模式后：

- 全部记录页隐藏普通一级 Dock，并在同一悬浮位置替换为选择 Dock；
- 项目详情本来不显示一级 Dock，直接在相同视觉位置显示选择 Dock；
- 选择 Dock 为单行紧凑布局，显示已选数量及导出、保存到相册、清理原图、删除四个图标按钮；
- 图标按钮保持至少 48dp 点击区域，并提供中文/英文 tooltip 和完整无障碍标签；
- 删除使用错误色，其余操作使用统一的强调色；
- 处理中仍保持同一高度，以细进度条和状态文字替换计数区域，不新增第二行大面板；
- 操作失败时保留选择并提示原因；操作成功后的退出规则沿用现有逻辑；
- 系统返回键和顶部完成按钮均先退出选择模式，再执行页面返回。

普通 Dock 与选择 Dock 互斥，任何时刻底部只允许出现一个悬浮操作面。

## 5. 项目返回动画

项目首页继续保留最近三张照片缩略图，但项目详情返回时不允许缩略图或记录列表参与二次重排。

- 项目详情改用整页剪裁的轻量水平位移与淡出，不再使用会同时缩放、交叉淡化页面内容的共享轴效果；
- 返回期间，底层项目首页保持已经绘制完成的稳定状态，不重新进入骨架屏；
- 最近照片缩略图沿用已解析文件和图片缓存，不在返回动画中重新显示占位再加载；
- 返回动画结束后再允许正常的项目摘要流更新；
- 开启“减少动画”时直接返回稳定的项目首页。

此调整只影响项目首页与项目详情之间的页面转场，不改变照片列表到照片详情的 Hero 动画。

## 6. 组件边界

- `RootNavigationScaffold`：拥有普通悬浮 Dock，并响应全部记录页的选择模式；
- `CapturePagedList`：继续负责分页与滚动，同时向上报告当前可见日期；
- 全部记录页和项目详情页：拥有各自的选择状态，决定是否显示选择 Dock；
- `CaptureBatchActionBar`：改为紧凑悬浮组件，继续调用现有批量服务；
- 路由转场：单独定义项目详情转场，不复用照片详情 Hero 转场。

组件之间只传递日期、选择状态和回调，不新增数据库字段或持久化状态。

## 7. 验收标准

- 项目详情返回首页的开始、中间和结束帧均无照片横向闪过、占位闪烁或列表重排；
- 普通 Dock 周围能够看到页面背景，不存在全宽底栏或分割线；
- 进入和退出选择模式时，记录列表可视高度不发生大幅缩短，底部始终只有一个 Dock；
- 360dp 宽度及 3 倍字体下，选择 Dock 无溢出，所有操作可点击并具备无障碍名称；
- 日期位于筛选右侧，跨天滚动能够正确更新，筛选到具体日期时保持固定；
- 最后一条记录可以滚动到 Dock 上方完整显示；
- 搜索、筛选、全选/取消全选、批量操作和返回顺序保持原有业务行为；
- Flutter 静态检查和全部测试、Rust 检查与测试、Android 单元测试及 debug APK 构建全部通过；
- 小米 15 真机重点复核返回动画、日期切换、Dock 悬浮感和选择模式可用空间。

## 8. 非目标

本轮不调整照片卡片字段、项目卡片信息、筛选面板内容、批量操作种类、照片 Hero、数据库查询和发布版本号。
