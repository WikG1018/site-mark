# SiteMark 1.0.0 界面收尾设计

## 目标

修复 PR #31 真机反馈的四项问题，并作为 1.0.0 发布：项目详情返回闪现、底部 Dock 偏高且选中态不完整、照片框选挤压卡片、多选操作缺少文字。

## 已确认设计

### 根页面与返回

- `RootBranchContainer` 不再用 `Stack + AnimatedOpacity` 同时合成三个根分支。
- 改用只绘制当前分支的 `IndexedStack`，继续保留项目、全部记录、设置各自的导航和滚动状态。
- 回归路径固定为：打开“全部记录” → 切回“项目” → 打开项目详情 → 返回；整个过程中隐藏的全部记录照片不得参与绘制。

### 根 Dock

- 使用自定义三等分目的地，不再依赖系统 `NavigationBar` 的默认高度和选中指示器。
- Dock 高度由 80 调整为 68，图标与文字作为一个整体垂直、水平居中。
- 选中背景同时包住图标和文字；支持系统“减少动画”。

### 照片选择与批量操作

- 进入选择模式后，复选框覆盖在缩略图左上角，不再占用独立横向空间。
- 已选卡片增加轻量边框/底色反馈。
- 批量操作 Dock 显示四个“图标 + 短文字”按钮：导出、存相册、清理原图、全部删除；危险操作继续使用错误色。
- 已选数量保留为紧凑区域，不能明显压缩照片列表可视高度。

## 发布

- 应用版本升级为 `1.0.0+15`，同步关于页面兜底版本与 README。
- PR #31 通过完整检查后合并到 `main`，从 `main` 提交创建 `v1.0.0` 标签并由发布工作流生成 APK。

## 验收

- 360dp 宽度和放大字体下 Dock 不溢出。
- 根 Dock 高度为 68，三项内容居中，选中背景覆盖图标和文字。
- 选择模式不改变缩略图与正文的横向起点。
- 批量操作四项均显示可读文字。
- 自动化测试覆盖“访问全部记录后再从项目详情返回”的复现路径。
