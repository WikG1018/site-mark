# SiteMark v0.9 记录搜索与分页设计

> 状态：已确认设计  
> 日期：2026-08-01  
> 依赖基线：`main` / `0.8.1+12`  
> 实施顺序：v0.9 第一项

## 1. 目标

项目记录和全部记录在数据量增长后，仍能快速搜索、筛选、滚动、批量选择和查看相邻照片。数据库负责筛选和分页，界面不再一次读取全部记录。

验收数据规模为 1 万条拍摄记录。本阶段不引入 FTS 全文索引；先以可解释的 SQLite 条件查询和稳定游标分页实现，并用数据量测试验证。只有实测不达标时，才另行设计全文索引。

## 2. 查询语义

统一查询对象包含：

- 可选项目 ID；
- 可选本地年、月、日范围；
- 搜索原文和规范化关键词；
- 分页游标；
- 每页数量，固定为 50。

搜索范围包括：

- 项目名称；
- 工程部位；
- 工作内容；
- 拍摄人；
- 备注；
- 照片编号；
- 地址。

搜索词先去除首尾空白、合并连续空白，再按空白拆成多个关键词。不同关键词之间采用 AND；每个关键词可以命中任一搜索字段。中文保持原文，英文字母忽略大小写。`%`、`_` 和转义符按普通文字匹配，不作为 SQL 通配符。

项目和日期筛选与搜索条件同时生效。查询排除 `pendingCamera`，保持当前可见记录边界。

## 3. 稳定分页

分页采用键集游标，不使用记录数量越大越慢的深层 `OFFSET`。统一排序键为：

1. `COALESCE(captured_at, created_at)` 倒序；
2. `id` 倒序。

下一页只读取严格位于上一页末尾游标之后的记录。数据库 schema 从 8 升到 9，并增加与项目、排序时间、记录 ID 对齐的游标索引。相同拍摄时间必须依靠 ID 保持稳定顺序。

分页控制器负责：

- 保存当前查询、已加载页面和末尾游标；
- 距离列表末尾 8 条时预取下一页；
- 按记录 ID 去重；
- 为每次查询分配递增版本，丢弃过期异步结果；
- 搜索或筛选变化时清空旧游标并回到顶部；
- 页面返回时保留查询、已加载页面和滚动位置。

## 4. 实时刷新

已加载记录的 `captured`、`rendering`、`ready` 和 `failed` 状态继续自动刷新，不因分页取消现有后台状态反馈。

新记录到达时：

- 用户位于顶部，自动刷新第一页；
- 用户已经向下滚动，显示“有新记录”提示，点击后刷新并回到顶部，避免列表突然位移。

删除或编辑记录后，分页控制器以当前查询重新建立游标，并以记录 ID 去重。任何刷新都不能把旧查询结果覆盖到新搜索条件上。

## 5. 筛选选项与结果统计

年、月、日选项改由数据库的去重或聚合查询生成，不再为了生成选项读取全部 `CaptureSummary`。全部记录页的项目选项继续来自项目表。

结果总数使用独立计数查询。第一页优先展示，计数稍后返回；计数失败不阻止浏览记录。

## 6. 界面行为

项目记录和全部记录右上角均提供搜索按钮。进入搜索后标题栏变为输入框：

- 只显示一个清空图标；
- 系统返回键先退出搜索，再执行页面返回；
- 搜索输入等待约 250 毫秒后提交；
- 清空搜索立即恢复当前项目和日期筛选结果；
- 搜索、项目或日期变化后退出编辑选择并回到列表顶部。

匹配工程部位、工作内容或拍摄人时沿用卡片已有字段。匹配备注、地址或照片编号时，卡片在搜索状态下增加一行简短命中说明，让用户知道记录为何出现。

首次加载使用现有 Skeletonizer。加载下一页只在列表底部显示小型进度提示，不替换整个列表。第一页失败显示错误和重试；下一页失败保留现有记录并在底部提供重试。无记录与查询失败必须使用不同状态。

## 7. 全选、批量操作和图片浏览

分页后的“全选”仍代表当前完整搜索及筛选结果，而不是当前已加载的 50 条。数据库只查询符合条件且状态为 `ready` 或 `failed` 的记录 ID，再交给现有批量操作流程。再次点击取消全选。

详情页和全屏查看不再接收完整记录列表。新增相邻记录查询接口，以当前查询和排序键获取前后记录；到达已加载边缘时预取相邻页。当前图片加载失败不应阻止用户返回，邻页失败只显示可重试状态。Hero 标识继续使用记录 ID，保持进入和返回动画一致。

## 8. 异常与一致性

- 所有 SQL 参数使用绑定值，不拼接用户输入；
- 搜索通配符必须转义；
- 分页结果必须按 ID 去重；
- 过期查询、计数和邻页结果必须丢弃；
- 下一页或计数失败不得清空已加载页面；
- 删除记录后若当前页变空，自动尝试补充下一页；
- 数据库迁移必须在事务内完成，失败时保留旧数据库状态。

## 9. 测试与验收

数据库测试覆盖：

- schema 8 到 9 迁移和全新建库；
- 1 万条记录的第一页、连续分页、筛选和计数；
- 相同拍摄时间下无重复、无遗漏；
- 中文、英文大小写、多个关键词、空白和 SQL 特殊字符；
- 项目、日期和搜索组合；
- 全部筛选结果的可操作 ID 查询；
- 前后相邻记录查询。

界面与控制器测试覆盖：

- 250 毫秒防抖和过期结果丢弃；
- 首次、下一页、空结果和错误状态；
- 搜索及筛选变化清除选择；
- 全选与取消全选覆盖未加载页面；
- 新记录提示不造成滚动跳动；
- 从详情返回后保留搜索、筛选、页面和滚动位置；
- 详情及全屏到达页边缘后继续加载。

自动化验收不使用容易受 CI 负载影响的硬编码毫秒阈值，但必须证明单页最多物化 50 条记录，并检查无搜索时使用游标索引。人工性能检查记录首次搜索、继续加载和返回列表是否存在可感知卡顿。

## 10. 不在本次范围

- FTS、自定义中文分词和高级布尔搜索语法；
- 云端搜索、跨设备索引或网络服务；
- 搜索系统相册中的非 SiteMark 图片；
- 修改照片文件、编号、水印或现有备份格式；
- 修改 Android 自动备份与设备迁移策略。
