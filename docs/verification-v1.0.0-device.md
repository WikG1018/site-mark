## 1. 安装与数据保留

- [ ] 全新安装可完成引导并创建项目  
- [ ] 从已安装的 **v1.0.4**（或更早版本）**覆盖安装**后，项目、记录、设置、私有原图仍在  
- [ ] 卸载警告已知：私有数据删除，系统相册 `Pictures/SiteMark` 通常保留  

## 2. 拍摄与后台队列

- [ ] 打开系统相机耗时可接受；取消拍照返回表单，不崩溃  
- [ ] 连续拍摄 **≥10 张**：返回后可立即再拍；工程部位/工作内容/拍摄人保留，备注清空  
- [ ] 列表状态：等待 → 处理中 → 完成；缩略图最终为水印成片  
- [ ] 处理中划掉最近任务再打开：任务继续或启动后恢复  
- [ ] （至少一台）重启设备后未完成任务被补偿  
- [ ] 系统相册同一照片编号**只有一份**最新成片  
- [ ] 定位拒绝仍可拍照；位置显示为不可用/未获取  
- [ ] 处理失败：界面为中英文友好文案，**无**路径/堆栈；原图保留时可重试  

## 3. 记录与项目

- [ ] 项目详情：搜索、筛选、多选、批量操作栏文字可读  
- [ ] 生命周期：进行中 → 已完成 → 已归档；非进行中禁止新拍摄  
- [ ] 置顶与排序符合预期  
- [ ] 删除项目：**不**删除系统相册已发布照片；SnackBar 说明清理状态  

## 4. 备份与恢复

- [ ] 设置与项目详情进入同一备份流程  
- [ ] 处理中照片阻止备份；失败照片需确认遗漏后才可备份  
- [ ] 单项目 / 多项目；含原图 / 不含原图 各至少一次  
- [ ] 系统保存面板：取消保存**不**显示成功，可再次保存/分享  
- [ ] 恢复前预览；普通分享 ZIP 被拒绝  
- [ ] 损坏/错误版本 ZIP 提示友好，无私有路径  
- [ ] 多项目恢复失败整体回滚  
- [ ] 恢复中强杀应用，再打开：半成品清理或 finalization 完成  
- [ ] 恢复后生命周期/置顶（schema v5）正确  

## 5. 界面与无障碍抽查

- [ ] 360dp 宽、大字体、浅色/深色、中/英：无严重溢出  
- [ ] 根 Dock 切换项目/全部记录/设置：无串帧、返回无照片列表闪现  
- [ ] 减少动画开启时转场可接受  
- [ ] 中端机连续浏览大量缩略图后切换根页：无明显卡死（见第 7 节内存观察）  

## 6. 诊断

- [ ] 设置 → 诊断：可生成 ZIP 并经系统分享  
- [ ] 抽查 ZIP：**无**项目名、照片路径、坐标、原始异常文本  

## 7. 内存与根分支保活（观察项）

当前根导航在切换时对来源/目标分支做短时双页合成，非当前分支 `Offstage` 保活以保留滚动与搜索状态。`main` 已限制 `imageCache`（约 40 张 / 32MB）并在内存压力时清空缓存。

真机观察（不必用 profiler 也可记主观感受）：

- [ ] 三页都滚过缩略图后反复切换 Dock，内存或卡顿是否明显恶化  
- [ ] 若某厂商机严重卡顿：记录机型与步骤，优先考虑后续“久置分支降图片缓存”而非去掉保活
