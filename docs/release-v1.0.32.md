# SiteMark v1.0.32

Android 版本：`1.0.32+47`。arm64 安装包版本代码为 `2047`，通用包为 `47`。
鸿蒙原生版本保持 `native-v1.0.14`，本次不发布 iOS 安装包。

## 本次更新

- 关于页新增应用内下载：显示百分比和已下载大小，支持取消、重试，离开页面后返回仍可查看当前进度。
- 下载完成检查大小和 SHA-256；安装前进一步检查包名、版本代码和签名，只把完整且匹配的 APK 交给 Android 系统确认安装。
- 首次未允许安装来源时提供明确说明和设置入口，不静默安装，也不会要求卸载旧版。
- 大字体下选择控件自动改为全宽圆角排列；筛选旁的日期保持可见，照片日期和处理状态避免互相挤压。
- 多选数量移至标题，底部玻璃操作栏保留四个带文字的按钮；退出编辑后恢复搜索内容。
- 详情预览和水印设置遵循系统“减少动画”；诊断读写、统计和清空按顺序执行，避免竞态。
- 包含 v1.0.31 的系统相机读写重开保留原图修复及后台脱敏诊断。

## 安装与升级

1. 已安装正式版的用户，请先手动下载与原安装类型一致的 `v1.0.32` APK，直接覆盖安装，不要卸载。
2. 此后从“设置 → 关于 → 检查更新”获取后续正式版本。应用会保持原有安装包变体，不随意切换 arm64 与 universal。
3. 首次应用内安装更新，需要在 Android 设置中允许工程印记作为安装来源，再返回点击“安装更新”。最终确认仍由系统完成。
4. 重要项目建议先做备份。Debug 测试包签名不同，不能用来覆盖正式版。
