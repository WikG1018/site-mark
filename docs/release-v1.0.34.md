# SiteMark v1.0.34

Android 版本：`1.0.34+49`。arm64 版本代码 `2049`，通用包 `49`。
本次仅发布 Android，不发布鸿蒙或 iOS 安装包。

## 本次更新

- **Dock 指示器滑动修复**：解决从“项目”切到其他入口时指示器被重新创建、直接跳到目标的问题。点击现在连续滑动；可以按住无色玻璃指示器横向拖动，松手切换到最近入口，取消手势不切页。保持无色玻璃，不使用淡绿色选中底。
- **滚动更从容**：顶栏和 Dock 不再因小幅调整、惯性滚动而反复收起。明显向下浏览才隐藏，反向滚动恢复；同一次手势分别累计 72/36dp，顶部 64dp 内保持显示，收放统一为 360ms。
- **自动检查更新**：安卓打开或回到前台时，每 24 小时最多检查一次公开版本信息。发现新版给出可关闭提醒，点击直接进入现有下载面板。可在“设置 → 关于 → 自动检查更新”关闭，手动检查始终保留。
- **不强制更新**：自动检查不会自动下载或安装，不上传照片、项目内容或诊断，不增加权限。提醒避让底部导航与新建按钮，拍摄、编辑、选择和键盘输入期间不遮挡操作；断网不弹出错误打扰。

## 升级说明

1. v1.0.32 / v1.0.33 用户可在“设置 → 关于 → 检查更新”下载本版。也可下载同变体 APK 直接覆盖安装；**不要卸载旧版**，重要项目先备份到应用外。
2. 保持安装变体：arm64 升级 arm64，universal 升级 universal。正式签名不变，下载校验大小和 SHA-256，安装前仍验证包名、签名和递增版本代码，由系统最终确认。
3. 数据库仍为 v17，无新增项目数据迁移。v1.0.33 的水印显示时间、相册导入和备份 v5/v6 兼容边界保持不变。
4. 默认开启的是前台自动版本检查，不是后台常驻服务；关闭后不再发起自动检查，已经查到的版本仍可手动下载。
