# SiteMark v1.0.33

Android 版本：`1.0.33+48`。arm64 安装包版本代码为 `2048`，通用包为 `48`。
鸿蒙原生仍为 `native-v1.0.14`，本次不发布鸿蒙或 iOS 安装包。

## 本次更新

- 水印时间：拍摄表单和记录编辑页新增“水印显示时间”，可选择日期、时间或恢复自动。只调整水印文字，保留原图、原始拍摄信息、照片编号和文件名；下一次拍摄恢复自动时间。
- 相册导入：在项目拍摄表单点击“从相册导入”，每批最多 20 张 JPEG/PNG。选中的照片复制到应用私有目录，再由后台队列添加水印；不修改或删除相册源照片，不申请整个相册的读取权限。
- 来源清晰：导入使用各自 EXIF 时间与位置；缺失时间则用导入时间并在详情说明，缺失位置不使用手机当前位置补填。详情区分原始信息与手动水印时间。
- 无色玻璃 Dock：更紧凑的悬浮圆角外壳、整体居中的图标文字，选中透镜滑动时轻微拉伸并收回，高光随方向移动；不用淡绿色底块。适配深浅主题、大字体、减少动画和高对比度。
- 修复 Windows 构建脚本的失败保护：缺失构建条件必须失败，避免生成缺少 Rust 核心却被误判成功的安装包。

## 升级与兼容性

1. `v1.0.32` 用户可在“设置 → 关于 → 检查更新”中下载本版，并由系统确认安装；旧版也可下载同变体 APK 覆盖安装。**不要卸载旧版**，重要项目先备份到应用目录之外。
2. 保持安装类型一致：arm64 升级 arm64，universal 升级 universal。两者正式签名一致，但版本代码不同，不能随意换用。
3. 数据库自动迁移到 v17。升级后不要直接降级安装；原有项目、记录和原图应保留。
4. 含相册导入或手动水印时间的项目使用备份格式 v6，需要本版或更新的兼容版本恢复；普通相机项目仍用 v5。当前鸿蒙版及旧 Android 版不能恢复 v6；旧备份继续可读。
5. 本批仅支持 JPEG/PNG，单张不超过 100 MB / 6400 万像素；HEIC、WebP、GIF 暂不支持。

## 验证与已知边界

两个功能批次的本地及模拟器证据见[时间与导入验证](verification-2026-10-23-watermark-time-gallery.md)、[Dock 验证](verification-2026-10-23-dock-redesign.md)。合并后的远程 CI、正式签名、哈希与发布状态以本版本 GitHub PR / Release 的实际记录为准。

最终组合代码本地复核：Flutter 1,246 项、Rust 46 单元 + 49 集成、发布/Windows 构建工具 18 项测试通过；Dart 格式、静态检查、Rust fmt/Clippy 通过。测试通过不等于正式包已发布。

- 模拟器不能代表厂商手机 Photo Picker、云相册、低空间、进程回收、真实拍摄及动画帧率；这些场景仍需用户真机确认。
- 记录重新生成后，新成片先安全发布，旧 URI 在后续启动核对引用后清理，因此系统相册可能暂时显示两份或增加重名后缀；应用内照片编号不变。
- 玻璃效果由 Flutter 自绘，不宣称使用 iOS 原生 Liquid Glass 或物理折射；本次不更改鸿蒙界面。
- 包含已有相机兼容性与安全更新修复，但无法恢复之前已损坏的原图。
