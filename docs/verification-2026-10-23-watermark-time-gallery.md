# 水印时间与相册导入验证

日期：2026-10-23。基线：`main` 的 `37503ff`。本次为未发布功能，不改当前稳定版下载链接及版本号，不合并或发布。

## 交付范围

- 拍摄表单与记录编辑页可调整水印显示时间，日期与时间均确认后才应用；支持恢复自动时间。
- 修改只作用于水印。原始拍摄信息、原图哈希、照片编号及排序保留，详情标明来源与“已手动调整”。
- 自定义时间只用于本次拍摄或导入批次；成功后下一次回到自动时间。
- Android 系统选择器多选导入，最多 20 张 JPEG/PNG，单张 100 MB / 6400 万像素以内。不增加广泛媒体权限，不改相册源照片。
- 默认按各自 EXIF 时间及 GPS 处理；无时间则用导入时间并明确标识，无 GPS 不补手机当前位置。
- 复制任务持久化，原子复制后复用后台串行队列；取消不建记录，部分读取失败保留成功项，数据库提交失败保留恢复任务。
- 数据库迁移到 v17；新语义备份使用 schema v6，普通相机项目仍为 v5。旧备份继续兼容。旧 Android 和当前鸿蒙版不能恢复 v6，不做有损降级。

## Android 模拟器实际操作

独立只读 AVD，Android 15 / API 35，1080×2400、420 dpi、字体 1.3 倍；测试英文、简体中文。
只用仓库图标和模拟相机图像，没有使用客户工程照片。

1. 创建测试项目，填入现场字段，从系统照片选择器多选 JPEG + PNG。
2. 两张均进入“已完成”，缩略图、成片、相册发布正常。JPEG 使用自身 EXIF 时间；PNG 无时间，使用导入时间，详情显示“照片未提供拍摄时间”。
3. 两份私有原图与选中源文件 SHA-256 逐一相同：JPEG `5b8c296b…`，PNG `df8a9bee…`。
4. 编辑 PNG 记录，把水印时间改为 `2026-10-20 08:30` 并重新生成；直接检查相册成片，时间文字正确。
5. 记录编号仍为 `Gallery-Test-SM-20261023-001`，原始时间仍标明未知，原图哈希未变；详情显示手动调整标记。
6. 结束并重新打开测试应用：两条记录、来源和自定义时间保留，旧成片清理正常。
7. 安装最终增量构建后，中文表单选择 `2026-10-22 04:19`，调用模拟器系统相机新拍：正常完成；记录实际拍摄时间为 10 月 23 日，成片水印为选定的 10 月 22 日。

## 已知边界与发版前待办

- 未验证厂商真机 Photo Picker、云相册下载、低空间、系统进程回收；相关恢复/失败窗口有单元测试，但不能代替真机。
- HEIC/WebP/GIF 本批不支持；选择后给出限制与重选提示。iOS、鸿蒙不新增相册入口，未构建其签名包。
- 重新生成沿用已有安全发布流程：先发布新成片，旧 URI 在下次启动核对全库引用后清理。系统相册可能暂时显示两份，并为新成片增加重名后缀；应用编号不变。
- 本地环境初次构建曾因缺失 `FLUTTER_ROOT` 产生没有 Rust 库却显示成功的 APK；现构建脚本已改为失败退出，并补回归。最终包检查已通过，未发布有问题的中间包。
- GitHub CI 结果以 PR 当前检查为准；本文仅记录本地证据。正式发版前需手机验证新拍、图库导入、时间修改、备份恢复以及保留数据升级。
